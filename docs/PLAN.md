# Real World Python Utilities - Development Plan

This document tracks the upcoming utilities, improvements, and roadmap for the "Real World Python Utilities" repository.

---

## 🎯 Project Vision

To build a collection of small, real-world Python tools that automate common daily tasks using only standard libraries or minimal dependencies.
Each script is standalone, readable, and educational for beginners learning practical Python scripting.

---

## 🗓️ Roadmap (Q4 2025)

| Priority  | Utility          | Description                                            | Status           |
| --------- | ---------------- | ------------------------------------------------------ | ---------------- |
| 🔥 High   | Todo CLI         | Simple terminal-based todo list manager (JSON storage) | 🛠️ In Progress |
| 🔹 Medium | Folder Organizer | Automatically sort files into categorized folders      | ✅ Done          |
| 🔹 Medium | File Renamer     | Batch rename files with custom patterns                | Planned          |
| 🔸 Low    | Notes CLI        | Minimal command-line note-taking tool                  | Planned          |
| 🔸 Low    | Text Analyzer    | Word count, frequency, and readability metrics         | Planned          |

---

## 🧠 Improvement Ideas

- Add unified CLI entry point to access all tools (e.g., `python main.py todo`, `python main.py organize`).
- Write tests for each tool using `pytest`.
- Add optional logging system for debugging and error tracking.
- Add CI/CD workflow for linting and testing via GitHub Actions.
- Add `requirements-all.txt` for contributors who want to test all tools together.

---

## 🧩 Long-Term Goals

- Convert some utilities into Python packages (PyPI ready).
- Create documentation website (e.g., with MkDocs or Docusaurus).
- Add GUI versions for selected tools using `tkinter` or `customtkinter`.
- Publish a “Learning from Real-World Python Scripts” article series.
